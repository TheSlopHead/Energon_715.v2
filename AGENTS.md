# AGENTS.md

This is a personal interactive portfolio website for **energon715**.

The website is built around a PS2-era low-poly 3D character that represents different parts of my personality, work, and interests.

Different parts of the character act as interactive sections of the portfolio:

- Brain / head — programming, GitHub projects, and things I build as a Go developer.
- Music — represented through musical objects inside/on the character.
- Film photography — represented by a film camera.
- Other body parts may represent travel, personal interests, and other parts of my life.

The main page presents **energon715** as a character/identity rather than a traditional portfolio page. The character is the main visual and interactive element.

The visual direction is inspired by PS2-era games, early-2000s interfaces, low-poly 3D graphics, old web aesthetics, and slightly strange/experimental digital art.

The site should feel personal, atmospheric, minimal, and slightly weird — not like a modern SaaS website or a standard developer portfolio.

Telegram posts appear in the background as fragments of thoughts/memories.

Overall concept: the visitor explores the person by interacting with the character and discovering what is inside them.
